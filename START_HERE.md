## 🐛 Troubleshooting

### Agent not responding?
```bash
curl http://localhost:8001/health
```

### Port in use?
```bash
netstat -ano | findstr :8001
taskkill /PID <PID> /F
```

### Still hanging?
1. Restart agent
2. Clear cache: `php artisan cache:clear`
3. Check firewall
