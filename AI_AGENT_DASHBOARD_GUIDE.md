## 🚀 HOW TO USE

### Step 1: Start Python Agent
```bash
cd c:\xampp1\htdocs\jewellery-management-system\python-ai-agent
python main.py
```

### Step 2: Open Dashboard
```
http://localhost:8080/ai-agent
```

### Step 3: Choose Feature

#### Option A: Chat
1. Type message in chat box
2. Select language
3. Click send

#### Option B: Voice
1. Click "Start Recording"
2. Speak your command
3. Click "Stop Recording"
4. Wait for response

#### Option C: Full Automation
1. Upload audio file
2. Select language
3. Click "Process Voice"
4. View results
