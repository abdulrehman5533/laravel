Open Command Prompt and run these commands one by one:

COMMAND 1: Navigate to Laravel
───────────────────────────────
cd c:\xampp1\htdocs\jewellery-management-system


COMMAND 2: Run Migrations (Create tables)
──────────────────────────────────────────
php artisan migrate


COMMAND 3: Seed Database (Add sample data)
───────────────────────────────────────────
php artisan db:seed


COMMAND 4: Clear Cache
──────────────────────
php artisan cache:clear


COMMAND 5: Cache Config
───────────────────────
php artisan config:cache


COMMAND 6: Start Laravel Server
────────────────────────────────
php artisan serve
